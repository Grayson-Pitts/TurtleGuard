# TurtleGuard

**Forecasting sea turtle nesting activity to help prioritize conservation efforts along Florida's coast.**

TurtleGuard is a research-oriented conservation planning website built for a 48-hour hackathon. It uses **Google Research's TimesFM 3.0** time-series foundation model to forecast sea turtle nesting activity for **2027**, then combines those forecasts with Florida Fish and Wildlife Conservation Commission (FWC) coastal data to visualize relative nesting priorities.

The website lets visitors explore Florida's nesting coast, compare predicted nesting concentrations, read about sea turtle conservation, and find volunteer organizations. **These are experimental nesting estimates-not measured litter hazards, verified cleanup needs, or probabilities that turtles will nest at a particular beach.**

## Features

- **Interactive Florida coastline map** using Leaflet, MapTiler tiles, and official FWC beach-line geometry.
- **Eight direct monitoring-area forecasts** generated by TimesFM 3.0 from historical annual nesting records (14 location/species time series).
- **Statewide estimated coverage** derived from TimesFM forecasts for 27 counties (81 county/species series), allocated among FWC surveyed shoreline segments.
- **Visually distinct coverage:** solid lines for directly forecasted monitoring areas, dashed lines for county-derived estimates, and gray where there is insufficient information. A map control can hide the estimated coverage.
- **Ranked nesting-priority index** based on projected *nests per mile*, with clickable beach details with higher scores ranked first.
- **Turtle species guide, conservation tips, and volunteer-opportunity directory** with county and activity filters.
- **Backtesting and audit outputs** to examine forecast behavior, data provenance, county allocations, and geographic matching.

## Quick start: View the website

Visit https://turtleguard.netlify.app/
 
### Alternatively, to run the website locally:

**Requirements:** Python 3 (Python 3.11 recommended)

1. Clone or download this repository.
2. Open a terminal in the repository's `TurtleGuard_BeachPriority` directory.
3. Start the local web server:

   ```powershell
   python -m http.server 8000 -d site
   ```

4. Open **http://localhost:8000**.
5. Keep the terminal open while using the website. Stop the server with **Ctrl+C**.

> Open the site through the local HTTP server, **not** by double-clicking `index.html`. The website fetches local JSON/GeoJSON files, which may not load properly from a `file://` URL.

If port 8000 is already in use, replace `8000` with another port in both the command and the browser address.

The repository already includes generated 2027 forecasts and map data. You do not need to install TimesFM, download model weights, or rerun the forecasts just to explore the website; however, the instructions for doing so are written below.

## Full setup: Regenerate TimesFM forecasts

Only complete this section if you want to run the forecasting pipeline or modify its data. The supplied forecast files let you skip it for normal website use.

### Requirements

- **Python 3.11** and `pip` (recommended environment for this project).

From the repository root, create a virtual environment inside `turtleguard_timesfm`.

**Windows PowerShell:**

```powershell
python -m venv turtleguard_timesfm\.venv
.\turtleguard_timesfm\.venv\Scripts\python.exe -m pip install --upgrade pip
.\turtleguard_timesfm\.venv\Scripts\python.exe -m pip install "timesfm[torch]" numpy
```

**macOS / Linux:**

```bash
python3 -m venv turtleguard_timesfm/.venv
./turtleguard_timesfm/.venv/bin/python -m pip install --upgrade pip
./turtleguard_timesfm/.venv/bin/python -m pip install 'timesfm[torch]' numpy
```

The optional Mote PDF-import utilities also require PyMuPDF:

```powershell
.\turtleguard_timesfm\.venv\Scripts\python.exe -m pip install pymupdf
```

To check the main model installation on Windows:

```powershell
.\turtleguard_timesfm\.venv\Scripts\python.exe -c "from timesfm3 import TimesFM3Evaluator; print('TimesFM 3 available')"
```

You may also run a synthetic smoke test on **Windows**:

```powershell
.\turtleguard_timesfm\.venv\Scripts\python.exe turtleguard_timesfm\smoke_test.py
```

On first use, TimesFM downloads `google/timesfm-3.0-pytorch` from Hugging Face and caches it locally. Model weights are **not** included in this repository.

### Run the entire pipeline

From the repository root, enter the application directory:

```powershell
cd TurtleGuard_BeachPriority
```

Run the following command on **Windows**:

```powershell
..\turtleguard_timesfm\.venv\Scripts\python.exe scripts\run_all.py --skip-weekly
```

Or on **macOS / Linux**:

```bash
../turtleguard_timesfm/.venv/bin/python scripts/run_all.py --skip-weekly
```

The pipeline runs these stages in sequence:

1. Load or download and validate official FWC shoreline geometry.
2. Generate 2027 direct TimesFM forecasts from `data/nesting_counts.csv`.
3. Generate 2027 county TimesFM forecasts from the 2021-2025 FWC county dataset.
4. Build dashboard data and direct-area nesting priorities.
5. Distribute county totals among mapped FWC segments using shoreline length and historical nesting-density classes.
6. Normalize direct and derived priority scores to a common statewide reference.
7. Run the audit and write reports identifying discrepancies and limitations.

Then launch the website with `python -m http.server 8000 -d site` and reload the browser.

**Useful pipeline options** (add after `scripts/run_all.py`):

| Option | Effect |
|---|---|
| `--skip-forecast` | Rebuild website data, mapped allocations, priority scores, and audits using **existing** direct and county forecast files; does not rerun TimesFM. |
| `--exclude-provisional-2026` | Omit provisional 2026 Mote annual counts when creating new direct forecasts. |
| `--refresh-fwc` | Download the official FWC GIS layer again rather than using the cached `site/fwc_beaches.geojson`. |
| `--batch-size 6` | Set the batch size for TimesFM inference (default: 6). |
| `--skip-weekly` | Compatibility flag; the experimental weekly forecasting pipeline is not part of the main run. |

For instance, to rebuild the site after adjusting presentation or length data **without rerunning the model**, run:

```powershell
..\turtleguard_timesfm\.venv\Scripts\python.exe scripts\run_all.py --skip-forecast
```

## Updating source data

- **Annual records:** Edit `data/nesting_counts.csv` using `location,year,species,nests`. Keep one nonnegative nest count for each location/species/year. Missing survey years must not be recorded as zero unless a verified zero was observed. Adding a brand-new location may also require appropriate beach-length and geographic mapping information.
- **Mote reports:** `scripts/merge_mote_annual_reports.py` can re-extract the included Mote annual-report PDFs and write candidate/conflict audit CSVs. It supports the report layouts included with this project; inspect its conflict report and back up `data/nesting_counts.csv` before using it with new documents. Weekly observations are stored separately from the annual forecasts. This operation is **not** automatically performed by `run_all.py`.
- **County data:** The county forecasting script currently expects complete 2021-2025 histories and targets 2027. Updating to a future season requires reviewing its fixed year range and target year across the scripts; simply adding a new CSV row is not sufficient.
- **Map tiles:** The front end uses MapTiler and Leaflet. If map tiles fail to load in a new deployment, check your internet connection and the `MAPTILER_API_KEY` in `site/index.html`; use a key configured for your deployment as needed.

## How the predictions and map work

**Direct forecasts:** Historical annual nest counts are grouped by monitored region and species. TimesFM predicts each series for 2027, and TurtleGuard sums the relevant species to obtain a region-wide nest-count forecast. The eight areas are Boca Raton, Canaveral National Seashore, Casey Key, Lido Key, Longboat Key, Siesta Key, Venice, and Volusia County. These use different forecast horizons because their source histories end in different years.

**County-derived estimates:** TimesFM separately forecasts loggerhead, green, and leatherback nesting totals for eligible Florida counties using their **five annual observations from 2021â€“2025**. TurtleGuard then distributes each county total among surveyed beach segments using mapped segment length and the FWC low/medium/high density categories. These are **not** independent TimesFM forecasts for every beach.

**Geographic matching:** FWC segments retain their official `OBJECTID` identifiers, so county-derived features do not rely on exact beach-name spelling. Direct monitoring regions use approximate geographic rules to associate forecasts with official FWC lines; those assignments are reviewable in `site/direct_match_review.csv`.

**Priority scoring:** Estimated nest counts are converted to **projected nests per mile** and mapped onto a shared relative scale (designed to top out at **90/100**, not 100% certainty). The result is a comparative nesting-concentration index, **not** a scientifically validated pollution score, turtle nesting probability, or field-work recommendation.
